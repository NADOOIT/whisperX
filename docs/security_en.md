# 🔒 Security & Data Protection

Learn how WhisperX protects your data and what you should pay attention to.

---

## 🔐 Data Storage

- Speaker profiles are stored **locally** on your machine (`~/.cache/whisperx/voice_profiles`)
- No automatic transfer to third parties

> ℹ️ **Note:** You can delete or transfer profiles to other systems at any time.

---

## 🕵️‍♂️ Data Protection

- Audio data and speaker profiles contain personal information.
> 🔒 **Recommendation:** Store sensitive data securely and encrypted.
- Regularly delete unnecessary profiles and audio files.
> 📝 **Tip:** Observe applicable data protection laws (e.g., GDPR).

## Security
- Only authorized users should have access to sensitive data.
- Regularly back up profiles and configurations.
- Apply updates and security patches promptly.
- Enable monitoring and logging to detect misuse early.
