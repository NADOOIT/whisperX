# Glossary (English)

Key terms related to speech recognition, AI, and WhisperX.

- **ASR (Automatic Speech Recognition):** Automatic conversion of speech to text.
- **LoRA (Low-Rank Adaptation):** Efficient method for adapting neural networks.
- **Embedding:** Numeric representation of features (e.g., voice).
- **VAD (Voice Activity Detection):** Algorithm for detecting speech segments.
- **Speaker Diarization:** Assigning text segments to individual speakers.
- **Batch Processing:** Processing many files in one run.
- **Fine-Tuning:** Further adapting a model to special requirements.
- **WER (Word Error Rate):** Error metric for transcription systems.
- **Diarization:** Speaker separation and assignment in the transcript.
- **Sentiment Analysis:** Automatic detection of sentiment in text.
- **Transcription Accuracy:** Degree of match between transcript and original audio.
