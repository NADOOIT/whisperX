# Glossar

Hier findest du zentrale Begriffe rund um Spracherkennung, KI und WhisperX.

- **ASR (Automatic Speech Recognition):** Automatische Umwandlung von Sprache in Text.
- **LoRA (Low-Rank Adaptation):** Effiziente Methode zur Anpassung neuronaler Netze.
- **Embedding:** Numerische Repräsentation von Eigenschaften (z.B. Stimme).
- **VAD (Voice Activity Detection):** Algorithmus zur Erkennung von Sprachabschnitten.
- **Speaker Diarization:** Zuordnung von Textsegmenten zu einzelnen Sprechern.
- **Batch Processing:** Verarbeitung vieler Dateien in einem Durchlauf.
- **Fine-Tuning:** Nachträgliches Anpassen eines Modells an spezielle Anforderungen.
- **WER (Word Error Rate):** Fehlermaß für Transkriptionssysteme.
- **Diarization:** Sprechertrennung und -zuordnung im Transkript.
- **Sentiment Analysis:** Automatische Erkennung von Stimmungen in Texten.
- **Transkriptionsgenauigkeit:** Maß für die Übereinstimmung von Transkript und Originalaudio.
